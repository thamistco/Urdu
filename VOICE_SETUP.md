# A single, consistent voice for pronunciations

By default, when you answer correctly the app pronounces the word/letter using
the **device's** text-to-speech. That's inconsistent (and some phones have no
Urdu voice). To give every learner the **same natural voice**, the app can play
a **pre-generated clip per word**, bundled into the build.

The clips are generated by `scripts/generate-voice.js` — which needs open
internet and a TTS API key, so it runs in **GitHub Actions** (or on your
machine), never inside the sandboxed Claude session.

## The easy path: let CI generate them
1. Pick a provider and get an API key:
   - **Google Cloud Text-to-Speech** — best Urdu voices (`ur-IN` WaveNet).
     Enable the API in Google Cloud, create an API key.
   - **ElevenLabs** — set a voice id too (multilingual v2 handles Urdu text).
2. Add the key as a repo **Actions secret** (Settings → Secrets → Actions):
   - Google: `GOOGLE_TTS_API_KEY`  (optional `VOICE_NAME`, default `ur-IN-Wavenet-A`)
   - ElevenLabs: `ELEVENLABS_API_KEY` **and** `ELEVENLABS_VOICE_ID`
3. Push anything (or re-run the **Deploy web preview** workflow). The build now
   generates ~65 clips and bundles them; the preview uses that one voice, and
   falls back to device TTS only for anything without a clip (e.g. letters).

## Local generation (optional)
```bash
GOOGLE_TTS_API_KEY=... npm run gen:voice   # writes assets/voice/*.mp3 + manifest
npm start
```

## How it works
- `scripts/generate-voice.js` reads every word/phrase, calls the TTS API, writes
  `assets/voice/<id>.mp3`, and regenerates `src/lib/voiceManifest.ts` (static
  `require`s so Metro bundles them).
- `src/lib/speech.ts` → `announce(id, urdu, roman)` plays the bundled clip if the
  id is in the manifest, else falls back to device TTS, else reads the Roman.
- Clips are git-ignored (`assets/voice/*.mp3`) — they're produced at build time,
  not stored in the repo. The committed manifest is empty until generated.

## Cost
~65 short clips is tiny — well within Google's and ElevenLabs' free tiers. You
only regenerate when the word list changes.
