## Changes to how the review runs

- **The text-to-speech key:** `generate-voice.js --cost` prices a run with no
  key and no request; with a key and without `--approved`, nothing is
  recorded; the deploy no longer generates clips. A full re-record is 20,095
  characters a voice: $0 inside the month's free million, $0.60 a voice past
  it, $3.01 a voice if every clip were retried to the cap.
- **New agents:** `qaaf-tester` (eight personas, rotated), `qaaf-content`
  (the course's moderator) and `qaaf-auditor` (checks the manager), and a
  "Checks and balances" section in the README with the run-health list.
- **The nightly instructions** were updated to match.

## What went wrong on the way

- **The P-105b finding was built on before it was re-measured.** The
  learning review's "four of eight never recognised" came from one shape of
  queue; the critic's ten varied sittings found one. A finding that motivates
  a change should be measured on the same harness as the change's test,
  before building.
- **The deploy could have spent the key unasked.** It passed a key secret,
  if one exists, to the generator on every build. Nobody had asked whether
  that secret is set, and this environment cannot see repository secrets. If
  it is set, it is now unused and can be deleted.
