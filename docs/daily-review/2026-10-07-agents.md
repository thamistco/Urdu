## What the manager learned

- **It broke two agents' tooling.** The manager changed
  `scripts/lib/serve-dist.js` in the working tree while the agents were
  driving the old build with it, so the door-opener looked for a button the
  build did not have. Design and QA both worked around it with their own
  copies, at a cost in calls. The README and the routine now say: edit
  nothing agents run while they run; use a worktree.
- **Its build command was wrong.** `HARF_BASE_URL=/Urdu … npm run build:web &&
npm run web:meta` sets the base for the first command only, so the built
  page lacked its base tag and every route dropped `/Urdu` (QA's finding 2).
  The deploy and `check:all` set it for both; the routine now exports it.
- A critic told what would change its verdict, and resumed for the re-check,
  is the cheapest second check: about 5 calls.
