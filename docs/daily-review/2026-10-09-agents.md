## What the manager learned

- **Write the number after adding it up.** A commit message tonight first said
  "594 cut-off labels"; the measured total was 483. It was corrected before
  anything was pushed.
- **A probe that does not finish proves nothing.** The first run of the Review
  probe stalled on the matching board and reported "Nothing to review yet" for
  both builds. That read like evidence until the stall was printed.
- **The fixed rule had a worse twin in the live one.** The critic's simulation,
  run against the old schedule, showed a word graded in every session growing
  to absurd intervals. P-009 fixed it without anyone looking for it.
