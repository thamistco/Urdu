**MAJOR (fixed): the new "no seat may be empty" rule was unreachable dead
code in the main histogram, and worse, produced a misleading diagnostic
when it should have fired.** `positions` was built from `answerAt`'s own
observed keys — a seat the shuffle can genuinely never reach has no Map
entry at all, so it is *absent*, never a real `count === 0` row. THE
CRITIC proved this live: mutating one seat to be structurally unreachable
silently shrank the printed histogram to one fewer entry, silently
recomputed `expected`/`p` for the wrong seat count, and the "never
reaches a position" message never fired — not preempted, unreachable. The
z-test still failed overall on the surviving seats' own skew (never a
silent pass), but the diagnostic shown was for the wrong distribution.
Fixed by building `positions` from the real seat range (0 through the
actual observed option count minus one, derived from `sizes` — already
asserted uniform by the floor check directly above, the same premise
`expected`/`p` already rested on) rather than only the keys `answerAt`
happened to have. Re-verified against THE CRITIC's exact repro: the same
mutation now correctly shows the dead seat at 0.0% in the histogram, the
z-test still fires on the surviving skew, and the "never reaches a
position" message fires too, both together, matching the floor-exempt
section's own already-correct behavior.

MINOR (fixed in passing): the doc comment's "measured real z-score ~1.3"
claim was a snapshot of one unseeded run, not a stable fact — reworded to
describe the range actually observed (well under 2, varies run to run)
