  2. Author a brand-new sentence, `s-257` ("دو لڑکیاں یہاں ہیں",
     demonstrating the fem. ‑ی→‑اں plural pattern لڑکی→لڑکیاں). Passed
     every code-correctness check run at the time (`check:shape`,
     `check:order`, `check:coverage`, `check:sentence-coverage`,
     `check:answerable`, `vitest`), but two independent problems surfaced:
     - CURRICULUM CRITIC found it MAJOR: g-plurals' existing four
       sentences already cover the ‑ا→‑ے, ‑ی→‑اں (کرسی→کرسیاں, s-167 —

       consonant→‑یں rows, so `s-257` duplicated already-covered ground

       authoring new content at all: a brand-new sentence has no recorded

       `check:voice` failed with "s-257: sentence has no clip" in both

     docs/store-listing.md, docs/CONTENT_NOTES.md) that `npm run audit`
     had required for it.
