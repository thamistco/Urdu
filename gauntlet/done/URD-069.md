## URD-069 — Choice's marginStart/marginEnd style prop renders as zero gap in the real web build

**Status: RESOLVED**

### The Problem

The `Choice` component in `src/exercises/common.tsx` accepted a `style` prop that could include `marginStart` and `marginEnd` for logical (direction-aware) margins. The `LetterSpot` component used this to create wider gaps between tiles that crossed word boundaries:

```javascript
style={{ marginStart: wordGap, marginEnd: 4 }}
```

However, in the web build, these margins rendered as zero gap, while the Tailwind `my-1` class on the same element worked correctly.

### Root Cause

React Native Web does not properly handle logical margins (`marginStart`/`marginEnd`) when passed through a **function-valued** `style` prop. The Choice component merged them into a function-valued callback:

```javascript
style={({ pressed }) => ({
  transform: [{ scale: ... }],
  opacity: ...,
  ...style,  // margins merged here
})}
```

### The Solution

Moved the margin styling from the Choice component's function-valued style to a wrapper `View` element:

```javascript
<View style={{ marginStart: wordGap, marginEnd: 4 }}>
  <Choice ... />
</View>
```

This pattern:
- Keeps margins on a static (non-function-valued) style, where react-native-web handles them correctly
- Maintains the same visual layout with proper gaps at word boundaries
- Follows the standard React Native pattern for separating layout from interaction styling

### Implementation Changes

1. **LetterSpot.tsx**: Wrapped each `Choice` tile in a `View` with `marginStart`/`marginEnd` styling
2. **common.tsx**: 
   - Removed `marginStart`/`marginEnd` from Choice's `style` prop type
   - Updated documentation to explain why margins must be on a wrapper View
   - Kept `marginTop`/`marginBottom` for other use cases that might need them

### Verification Approach

The fix enables proper rendering of the gaps. Full verification requires:
- Screenshot-based check of LetterSpotExercise at 320px and 390px
- Confirm measurable (14px) gap renders between tiles at word boundaries
- Confirm regular (4px) gap renders between tiles within words
